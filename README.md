# SQLink

> 一款运行在 iPhone / iPad 上的**原生 MySQL 客户端**，让你在没有电脑时也能随时连接、浏览、维护 MySQL 数据库。

## 这是什么

SQLink 是一个用 **SwiftUI** 原生开发的 iOS 应用。它直接通过 MySQL 网络协议（支持 TLS 加密）连接你的 MySQL / MariaDB 服务器，把数据库表、数据、SQL 查询搬到手机上，方便随时随地处理线上数据。

- 不依赖任何第三方中转服务，连接信息加密保存在系统钥匙串（Keychain）。
- 访客模式：无需注册账号也能直接连接数据库使用基础功能。
- 会员（Pro）：解锁无限查看 / 导出等高级额度。

## 主要解决什么问题

- 📱 **移动运维**：服务器告警、临时查数、改个配置，不必开电脑、不必连 VPN 后再开 Navicat。
- 🔍 **随时核对数据**：线上数据有疑问，掏出手机连上就能看。
- ✏️ **轻量维护**：直接在手机上改一行配置、插一条数据、跑一条 SQL。
- 🔒 **安全**：原生协议 + TLS，密码仅存于本机 Keychain，不上传明文。

## 功能特性

- 多数据库连接管理（保存 / 编辑 / 删除）。
- 数据库 / 表浏览，查看表结构。
- 表数据浏览、单元格编辑、筛选（Filter）与排序（Sort）。
- SQL 查询控制台，执行自定义语句。
- 数据导出。
- 账号体系：邮箱注册 / 登录 / 找回密码；激活码开通**永久会员**。
- 意见反馈。

## 如何安装

1. 打开本仓库的 [Releases](https://github.com/jiayuLian/SQLink/releases) 页面，下载最新的 `SQLink.ipa`。
2. 通过 TrollStore 把 IPA 安装到设备。
3. 打开 App 即可使用（无需账号也能以「访客」身份连接本地 / 内网数据库）。

## 如何使用

### 1. 添加数据库连接
在「连接」页点 `+`，填写：

- 连接名（自定义）
- 主机 / 端口（默认 3306）
- 用户名 / 密码
- 默认数据库（可选）
- 是否启用 TLS

保存后即可连接。

### 2. 浏览与编辑数据
进入某个数据库 → 选择表 → 查看数据。支持：

- 点击单元格查看 / 编辑长文本
- 顶部「筛选 & 排序」添加条件
- 翻页浏览

### 3. 运行 SQL
在「查询」页输入 SQL 语句并执行，结果可导出。

### 4. 会员（Pro）
免费版有查看 / 导出行数上限；开通**永久会员**后解除限制：

- 在「我的」页点「激活码开通会员」
- 输入作者提供的激活码即可立即生效（本地永久判定，离线可用）

## 关于后端与账号

App 的**账号 / 会员 / 反馈**功能依赖一个自托管的后端 API 服务（Node.js + MySQL + Redis）。该后端：

- 负责邮箱注册登录、激活码校验、反馈收集；
- **不存储你的数据库连接密码**（密码仅存于手机 Keychain）。

> 仅使用本地数据库连接、不需要账号功能时，可完全跳过后端，以访客模式使用。

## 从源码构建

- 环境：macOS + Xcode 16（GitHub Actions 使用 `macos-14` + Xcode 16 自动打包）。
- 依赖：XcodeGen（`project.yml` 生成 `.xcodeproj`）。
- 本项目通过 GitHub Actions 自动构建并发布到 Releases；仓库仅保留一个 Release 版本（`v1.0.10`）。

## 技术栈

- Swift / SwiftUI
- 原生 MySQL 协议实现（`MySQLWire` / `MySQLConnection`，支持 TLS）
- 后端：Express + MySQL2 + Redis + JWT（独立部署）
